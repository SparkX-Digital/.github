## VectorCP
**Open-source hosting control.**
VectorCP is a self-hosted hosting control panel for server owners, resellers
and customers. It brings website management and delegated hosting into one
interface, with source code you can inspect, change and contribute to.
VectorCP is in early development. The repository documents what works today,
what has been tested and what is still planned.
